# Løfte Studios — Claude Code Website Kit

This kit directs Claude Code to build an original, premium Løfte Studios marketing website.

## Use it

1. Create an empty project folder and copy this kit into it.
2. Open Terminal in that folder and launch `claude`.
3. Paste the full contents of `MASTER_PROMPT.md`.
4. Work in order. Claude must complete and verify one phase before beginning the next.

The desired quality bar is cinematic, editorial, motion-led digital storytelling. It may take inspiration from the *category* of premium sites such as Clear Street, but must not reproduce their layouts, copy, assets, trademarks, interface designs, or video treatments.

## Included files

- `MASTER_PROMPT.md` — the complete instruction to paste into Claude Code.
- `DESIGN_BRIEF.md` — approved creative direction and visual guardrails.
- `SITE_AND_CONTENT.md` — page architecture and starter content.
- `ASSET_CHECKLIST.md` — assets to replace before launch.
- `MAC_SETUP.md` — development tools and install order.

## Scope

Build a public-facing marketing site, not a client portal. Do not build an account/login system, payments, or a complex backend unless explicitly requested.
