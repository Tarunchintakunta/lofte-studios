# Site map and starter content

## Global navigation

Logo | Services | Selected work | Our approach | About | Insights | Start a project

Mobile: logo, concise menu trigger, and a visible “Start a project” action. The menu must be keyboard accessible and lock background scroll when open.

## Home

1. **Hero** — Headline: “Stories that move brands forward.” Supporting copy: “Løfte Studios shapes clear, culturally fluent content across words, motion, sound, and visual systems.” CTAs: Start a project / See selected work.
2. **Capabilities as a signal field** — Copy, Video, Visual, Audio; short outcome-led statements rather than generic descriptions.
3. **Why Løfte** — “A complete content studio, without the usual handoffs.” Explain strategy + production + localization + delivery.
4. **Selected work** — CMS-driven case-study preview grid with 3–6 real pieces or visible placeholders.
5. **The Løfte method** — Discover, Design, Develop, Distribute, Deconstruct, Deliver. This is the one true numbered sequence.
6. **Proof** — client logos and approved testimonials only.
7. **Closing CTA** — “Have a story worth lifting?” Start a project.

## Services overview

Group services by outcome:

- **Words with direction** — content strategy, copywriting, editing, transcreation, localization, translation.
- **Visual systems that carry the message** — graphic design, infographics, illustration, presentations, social assets.
- **Motion made to be understood** — video editing, scripting, storyboards, captioning, subtitling, motion assets.
- **Sound with a point of view** — narration, audio cleanup, audio localization.
- **Reach and refinement** — publishing, engagement optimization, performance analysis, content distribution.

Each service page must include: what it solves, deliverables, process, selected work, optional FAQ, and a project CTA.

## Selected work

Build a CMS-backed listing with filters for Copy, Video, Visual, Audio, Localization, and Strategy. Each case study includes title, client (optional), sector, service tags, cover asset, short challenge, approach, deliverables, results only when supplied, gallery/video, and CTA.

## About

Describe Løfte as a focused team that blends strategic thinking with practical production. Include a short studio story, team section only if assets are supplied, working principles, and contact CTA.

## Insights

CMS-backed articles with category, author, date, rich content, OG image, related articles, and newsletter/contact CTA. Do not launch an empty Insights page as a prominent nav item; hide it until articles exist or use a simple “Notes” landing page.

## Contact

Project form fields: name, work email, company, website (optional), required service(s), approximate budget (optional), desired timing, project summary, consent checkbox. Send to the approved inbox; show a graceful success state without claiming a specific response time unless approved.
