# Asset checklist

Claude must start with labelled placeholders, never invented “real” work. Replace these before production launch.

## Required

- SVG logo (light and dark variants if available)
- favicon and social sharing image
- approved email address and phone number
- legal business name, privacy-policy text, and address if displayed
- 3–6 portfolio case studies: title, client permission, category, cover image/video, short description
- approved client logos and testimonial approvals

## Recommended

- 8–15 high-resolution portfolio stills (WebP or AVIF where possible)
- 2–3 short muted motion loops, 6–12 seconds each, as WebM + MP4 plus poster images
- founder/team imagery if the About page needs it
- brand guidelines, past decks, and written tone examples

## Media production rules

- Prefer video below 3 MB per initial section; defer non-critical media.
- Produce desktop and mobile crops where a composition does not survive a narrow viewport.
- Use `preload="metadata"`, poster images, lazy loading, and a reduced-motion fallback.
- Do not install Blender for this site unless the approved creative concept includes an actual custom 3D scene.
- After Effects is optional: use it to make original video loops or kinetic typography, then export. An After Effects MCP connection is not needed to build the website.
